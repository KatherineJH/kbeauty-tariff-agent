검토일 2026-11-05. 각 원천의 이용 조건을 **다운로드 전에** 읽고 기록한다.

**수집 현황(2026-11-05):** D2 완료(8개 파일, 약 15MB), D4 완료(20건, 약 2MB). **D3는 이번 버전에서 제외**(사용자 결정 2026-11-05, 아래). 각 폴더의 `PROVENANCE.md`·`manifest.csv` 참고.
수집 후에는 원천별 `data/raw/<원천>/PROVENANCE.md`에 요청 주소·수집 시각·해시를 따로 남긴다.

## 검토 중 새로 확인한 범위

- **HTS 99장(9903 소호)도 필요하다.** 상호관세 같은 추가 관세는 33장이 아니라 99장의 임시 소호로 부과된다. 시나리오 S2(날짜별 규정 적용)에 필수라서 D2 범위에 넣는다.
- 한국 관련 일반 주해 33(한-미 FTA)과 일반 해석 규칙(GRI)도 D2 범위에 넣는다.

## D3 자동 수집 불가 (2026-11-05 확인)

CROSS 검색 API는 요청마다 보안 토큰을 요구한다(응답: "Security parameters are missing from this request context."). 화면에 봇 탐지(reCAPTCHA 계열) 표시가 있다. **봇 탐지 우회는 하지 않는다.**
대안:
1. 사용자가 브라우저에서 직접 검색해 필요한 판정례를 내려받는다(소규모, 사람의 정상 이용).
2. 홈 화면의 공식 "Latest rulings" CSV·ZIP(최근 30일분)만 자동 수집한다. 화장품 판정례는 거의 없을 것이다.
3. D3 없이 HTS 주(註)·관보·CBP 공개 안내문(cbp.gov, 퍼블릭 도메인)으로 분류·규정 질문을 구성한다.
