# 사전 등록 — DRAFT (효력 없음)

> **DRAFT. 아직 작성 전이며 사전 등록으로서 효력이 없다.** 효력은 이 줄의 "DRAFT"를 지우고 본문을 채운 커밋부터 생긴다.
> 평가셋을 만들고, 어떤 시스템 구성도 test 셋으로 실행하기 **전에** 작성해 커밋한다. 커밋 시각이 사전 등록의 증빙이다.
> 분석 중 이 문서와 다르게 진행한 부분은 지우지 않고 맨 아래 "변경 기록"에 이유와 함께 **행을 추가**한다.

작성 예정 항목:

1. 질문 유형(S1~S6)과 평가셋 구성·분할 규칙, test 셋 SHA-256
2. 비교 구성(B0, B1, R1~R5, AG0, AG, MA)과 고정 파라미터(모델 ID·가격표 날짜·프롬프트 해시)
3. 주 가설 H1~H4(H4는 질문 유형별), 주 지표, 검정, Holm 보정, 판정 규칙(지표가 반대로 움직일 때 포함)
4. 비용 규칙: 성공률 차이가 유의하지 않으면 더 싼 구성 채택
5. 검출 한계(MDE)
6. 독립 검수 절차(사용자 기준 라벨, Claude·Codex 재라벨 범위, LLM 심판 검증 기준)
7. 시점 홀드아웃 수집 규칙
